# LexaVoxa - Proyecto de Aula

Aplicativo web orientado al aprendizaje del idioma inglés, desarrollado con Java (Spring Boot), MongoDB y tecnologías frontend (HTML, CSS, JavaScript). Su propósito es mejorar la motivación, la constancia y el seguimiento del progreso de los estudiantes mediante cursos, lecciones, tests, ranking y elementos de gamificación (experiencia, niveles y logros), ofreciendo una alternativa accesible que evite el exceso de funciones de pago.
